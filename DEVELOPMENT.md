# Scorpena – для разработчиков

Технические заметки: как устроена программа, сборка и выпуск. Для пользователей см. [README](README.md).

Нативное приложение для macOS: вставляешь ссылку на видео (**YouTube, VK,
Instagram, TikTok, Vimeo** и [почти 1750 других сайтов](https://github.com/yt-dlp/yt-dlp/blob/master/supportedsites.md))
— получаешь файл. Само приложение — удобная оболочка вокруг **yt-dlp**
(скачивание), **ffmpeg** (склейка потоков, конвертация) и **deno** (нужен
yt-dlp, чтобы решать проверки YouTube).

**Скачать:** [последний релиз](https://github.com/erickkey/Scorpena/releases/latest) →
`Scorpena.dmg`.

## Что умеет

- Видео — в **MP4, MOV, WebM или MKV**, звук — в **MP3 (320 kbps), WAV или M4A (AAC)**.
  Формат выбирается под полем ссылки (Видео или Звук), и кнопка «Скачать» сохраняет именно его.
- Показывает доступное качество и размер файла до скачивания.
- Сама подставляет ссылку из буфера обмена, подсказывает, если это не ссылка или
  не страница видео.
- Пауза и докачка: останавливает скачивание, а если программу закрыли или пропал
  интернет — продолжает с того места, где остановилось.
- Ограничение скорости (ползунок в «Дополнительно», в Мбит/с).
- История последних 20 скачиваний.
- Обновляется одной кнопкой; встроенный yt-dlp обновляется сам, в фоне.
- Русский и английский интерфейс.
- Работает на Intel и Apple Silicon, macOS 13 и новее.

Не умеет: DRM-видео (Netflix, Кинопоиск и т.п.), плейлисты целиком, идущие
прямые эфиры, субтитры и вырезание фрагментов.

## Что внутри приложения

Всё вшито в `Scorpena.app/Contents/Resources/bin/`, ничего ставить не нужно:

- `yt-dlp` + папка `_internal` — официальная сборка **«onedir»** (`yt-dlp_macos.zip`):
  запускается за доли секунды (одно-файловая сборка распаковывала себя при каждом
  запуске, ~8 с). Сама обновляться не умеет — это делает приложение (см. ниже);
- `ffmpeg` — статическая сборка ([eugeneware/ffmpeg-static](https://github.com/eugeneware/ffmpeg-static)), universal;
- `deno` — JS-движок, который yt-dlp использует для проверок YouTube, universal.

Из системы ничего не берётся: приложение работает одинаково на любом Mac. Если
файлы внутри повреждены или удалены, оно покажет плашку «Внутри программы не хватает
файлов» и предложит скачать Scorpena заново.

### Обновления

- **yt-dlp** — раз в сутки при запуске (и по кнопке «Проверить сейчас» в
  «Дополнительно»). Только stable-версии. Новая версия скачивается, проверяется по
  SHA-256 из релиза, распаковывается рядом со старой и должна пройти
  самопроверку на публичном видео **до** замены; если нет — остаётся старая.
  Журнал: `~/Library/Application Support/VideoDownloader/tool-update.log`.
- **Само приложение** — кнопка «Доступно обновление» (подсвечивается, если
  `version.json` в репозитории новее установленной версии). Скачивает релизный
  DMG, проверяет (bundle id, версия, подпись, инструменты на месте), заменяет себя
  и перезапускается; если новая версия не запустилась — возвращает прежнюю.

## Видео, требующие входа (возрастные / приватные / для участников)

Всё автоматически. При скачивании приложение:

1. пробует без cookies (обычные видео так и качаются);
2. если сайт просит вход — по очереди пробует cookies из установленных
   браузеров: **Safari**, Chrome, Firefox, Яндекс;
3. запоминает, что сработало, и в следующий раз пробует это первым.

Единственное, что нельзя сделать за пользователя, — выдать **Полный доступ к
диску** (защита macOS). Он нужен, только чтобы прочитать cookies **Safari**.
Если приложение упрётся в это, оно покажет плашку с кнопками «Открыть настройки»
и «Показать приложение».

## Отчёты и приватность

- «Сообщить об ошибке» и «Обратная связь» отправляют сообщение разработчику в
  Telegram-бота — только по нажатию пользователя.
- Автоматические анонимные отчёты о серьёзных сбоях (падение, откат обновления,
  не запускается встроенный инструмент, несколько неудач подряд) можно отключить
  в «Дополнительно». Ограничены по частоте.
- Статистика скачиваний — только счётчик скачиваний релизов на GitHub; самих
  пользователей программа не отслеживает.

## Сборка (без Xcode)

Нужны только Command Line Tools (`xcode-select --install`) и интернет. Файл
`YouTubeDownloader/Secrets.swift` (токен бота) не хранится в репозитории — его
нужно создать:

```swift
enum Secrets {
    static let telegramBotToken = "..."
    static let telegramChatID = "..."
}
```

```bash
sh Scripts/build-app.sh            # собирает Scorpena.app (arm64 + x86_64) на рабочий стол
sh Scripts/package.sh ~/Desktop/Scorpena.app ~/Desktop
```

`build-app.sh` компилирует Swift через `swiftc`, собирает `.app`, скачивает
yt-dlp (с проверкой SHA-256), ffmpeg и deno, подписывает ad-hoc. `package.sh`
делает `Scorpena.dmg` (окно со стрелкой → «Программы»), `Scorpena.zip` и
`VideoDownloader.dmg` — то же приложение в папке со старым именем: программы версии
2.1 и старше обновляются, скачивая именно `VideoDownloader.dmg`, поэтому этот файл
нужно прикладывать к каждому релизу.

Проверка типов без сборки:

```bash
swiftc -typecheck -sdk "$(xcrun --show-sdk-path)" -target arm64-apple-macosx13.0 YouTubeDownloader/*.swift
```

(Файл `YouTubeDownloader.xcodeproj` остался от старой сборки через Xcode и не
обновляется — новые файлы в нём не перечислены.)

## Релиз

1. В `Scripts/build-app.sh` поднять `APP_VERSION`, в `ContentView.swift` добавить
   текст в `changelog` для этой версии.
2. Собрать и упаковать (см. выше).
3. Создать релиз на GitHub с **двумя** файлами: `Scorpena.dmg` и `VideoDownloader.dmg`.
4. Последним поднять `version.json` в корне репозитория — только после этого
   у пользователей загорится «Доступно обновление».

## Раздача друзьям

Приложение **не нотаризовано** (нужен платный Apple Developer, $99/год), поэтому
при первом запуске, если скачано из браузера:

- правый клик по `.app` → **Открыть** → **Открыть**; либо
- если пишет «не удаётся открыть» / «повреждено» — в Терминале:
  ```bash
  xattr -cr /Applications/Scorpena.app
  ```
- если и это не помогло — **Системные настройки → Конфиденциальность и
  безопасность** → внизу будет строка про заблокированное приложение →
  **«Открыть в любом случае»**.

Обновление изнутри приложения (кнопка «Доступно обновление») этих шагов не
требует. Пересылать DMG лучше через AirDrop, облако или ссылку на релиз — не через
Telegram/WhatsApp: они пересжимают файлы, и macOS потом считает приложение
«повреждённым».

## Как работает выбор формата

Вариант для MP4 (по умолчанию) — yt-dlp запускается примерно так:

```
yt-dlp --newline --no-color --no-playlist --ffmpeg-location <dir> \
  -f "bv*[vcodec^=avc1]+ba/b[vcodec^=avc1]/bv*+ba/b" \
  -S "vcodec:h264,res,ext:mp4,br" \
  --merge-output-format mp4 --remux-video mp4 \
  -o "<папка>/%(width)sx%(height)s %(title)s (Scorpena video downloader).%(ext)s" \
  <URL>
```

- **MP4 / MOV** — H.264. Формат-селектор берёт готовый H.264-поток, если он есть;
  иначе после скачивания приложение проверяет файл через `ffmpeg` и, если видео
  VP9/AV1, перекодирует в H.264 (`libx264 -crf 20`, звук → AAC).
- **WebM** — потоки VP9/Opus; если сайт отдаёт другое, перекодируется в WebM.
- **MKV** — лучшие потоки сайта без перекодирования.
- **Звук** — MP3 320 kbps / WAV / M4A; в MP3 и M4A вшиваются обложка и теги.
- При включённом ограничении скорости потоки качаются по одному (иначе лимит
  yt-dlp применяется к каждому параллельному потоку отдельно).

## Файлы

| Файл | Назначение |
|------|-----------|
| `YouTubeDownloaderApp.swift` | точка входа, окно |
| `ContentView.swift` | весь основной UI, «Дополнительно», «О программе», обратная связь, проверка обновлений |
| `DownloadManager.swift` | запуск `yt-dlp`/`ffmpeg`, разбор прогресса, пауза, докачка, повторы |
| `DownloadSettings.swift` | форматы видео и звука, ограничение скорости, незавершённое скачивание |
| `DownloadHistory.swift` | история скачиваний |
| `ToolLocator.swift` | поиск `yt-dlp` / `ffmpeg` внутри приложения |
| `ToolAutoUpdater.swift` | безопасное обновление встроенного yt-dlp |
| `AppInstaller.swift`, `UpdatePanel.swift` | обновление самого приложения |
| `AppRenamer.swift` | переименование файла при переходе со старого названия |
| `DiagnosticReporter.swift` | анонимные отчёты о сбоях |
| `SupportedSites.swift` | список известных сайтов для подсказок |
| `Localization.swift` | русский и английский тексты |
| `Scripts/build-app.sh`, `Scripts/package.sh` | сборка и упаковка |

## Замечания

- App Sandbox выключен намеренно — иначе запуск сторонних бинарников и запись в
  произвольную папку невозможны; в Mac App Store такое не выложить.
- Скачивай только то, на что у тебя есть право (свои видео, материалы под
  свободной лицензией, разрешённое правообладателем).
