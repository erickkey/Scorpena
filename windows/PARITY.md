# Windows vs Mac: что совпадает с Mac-версией

Статус: ✅ сделано и проверено на Mac (в режиме разработки) · 🟡 сделано, но не проверено глазами или на Windows · ❌ не сделано · ➖ на Windows не применимо.
Главное ограничение: ничего из этого ещё не запускалось на настоящем Windows.

| Что | Статус |
|---|---|

| Формат «Видео» (MP4, MOV, WebM, MKV) и «Звук» (MP3, WAV, M4A), активна одна строка | ✅ |
| «без звука», «Качество: …», «Папка: …» | ✅ |
| Меню качества: «Проверить качество», «Максимальное — ≈ N МБ», размеры по разрешениям | ✅ |
| Строка прогресса: «Скачивание… N% · скорость», «Пауза», «Продолжить», «Отменить», «Показать файл», счётчик «N с» | ✅ |
