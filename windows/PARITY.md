# Windows vs Mac: что совпадает с Mac-версией

Статус: ✅ сделано и проверено на Mac (в режиме разработки) · 🟡 сделано, но не проверено глазами или на Windows · ❌ не сделано · ➖ на Windows не применимо.
Главное ограничение: ничего из этого ещё не запускалось на настоящем Windows.

| Что | Статус |
|---|---|

| Сначала без cookies, потом браузеры; порядок по первому запуску; запоминание сработавшего | ✅ путь «нужен вход» (YouTube 18+): без cookies → браузер → то же сообщение, что на Mac · 🟡 успешная загрузка с реальным входом не проверена |
| Проверка входа в браузеры при первом запуске (только имена cookies) | 🟡 |
| Перекодирование MP4/MOV в H.264 | ✅ |

Цепочка окно → куки → повтор проверена на Mac · 🟡 вход через Google на Windows не проверен |
